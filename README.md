# Restaurant Operations Simulation

## Overview
Developed a discrete-event simulation of a five-station restaurant operation using Simio to evaluate how staffing decisions and order volume affect operational performance.

The model represents both in-person and online ordering workflows using historical transaction data and realistic operating logic.

---

## Objective

The objective of this project was to evaluate operational performance under different staffing and demand scenarios while maintaining a target service level.

---

## Tools Used

- Simio
- Microsoft Excel

---

## Model Features

- Five-station restaurant process
- In-person and online customer workflows
- Historical demand data
- Queueing and service logic
- Multiple simulation replications
- Staffing scenario analysis
